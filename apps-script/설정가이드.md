# 상담 신청 → 구글 시트 연결 (약 10분)

홈페이지 상담 신청서(3단계 드로어·상담 페이지)가 구글 시트에 쌓이고 메일로 알림이 오게 하는 설정입니다. 연결 전에는 신청 내용을 정리해 보여 주고 전화·카카오톡으로 안내하며, **저장은 되지 않습니다.**

1. 구글 드라이브에서 새 스프레드시트를 만듭니다(이름 예: `미래애드원 상담신청`).
2. 메뉴 **확장 프로그램 → Apps Script** 를 엽니다.
3. 기본 `Code.gs` 내용을 모두 지우고, 이 폴더의 `Code.gs` 를 붙여 넣습니다.
4. 맨 위 `CONFIG.NOTIFY_TO` 에 알림 받을 메일 주소를 넣고 저장합니다.
5. 함수 선택에서 `setup` 을 고르고 **실행** → 권한 승인(구글 계정 소유자가 직접).
6. **배포 → 새 배포 → 유형: 웹 앱**
   - 실행 사용자: 나
   - 액세스 권한: 모든 사용자
   - 배포 후 나오는 `https://script.google.com/macros/s/…/exec` 주소를 복사합니다.
7. 사이트의 `assets/js/config.js` 에서 `LEAD_ENDPOINT: ''` 따옴표 안에 주소를 붙여 넣고 다시 배포합니다.
8. 사이트에서 테스트 신청을 한 번 넣어 시트에 행이 생기고 메일이 오는지 확인합니다. 테스트 행은 상태를 `종료`로 바꾸거나 지웁니다.

## 시트 사용법
- **상태** 칸: 신규 → 연락완료 → 상담중 → 견적발송 → 계약 / 보류 / 종료 (기획서 11장 문의 상태값)
- **담당자·메모** 칸은 직접 입력합니다.
- 유입 경로(utm, 네이버 검색어, 첫 랜딩 페이지)가 자동으로 함께 저장됩니다.

## 주의
- 코드를 고친 뒤에는 **배포 → 배포 관리 → 수정 → 새 버전**으로 다시 배포해야 반영됩니다(주소는 그대로).
- 개인정보처리방침(사이트 /privacy/)에 "Google Workspace(구글 시트·메일)에 저장될 수 있음"이 적혀 있습니다. 다른 도구로 바꾸면 방침도 고쳐야 합니다.

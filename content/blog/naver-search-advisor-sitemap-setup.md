홈페이지를 만들었다면 네이버 서치어드바이저에 사이트를 등록하고, 소유 확인을 마친 뒤 사이트맵과 RSS를 제출하는 순서로 진행하면 됩니다. 마지막으로 중요한 페이지를 골라 수집을 요청합니다. 네이버 아이디만 있으면 무료로 할 수 있고, 준비만 되어 있다면 처음 해도 한자리에서 마칠 수 있는 분량입니다.

## 등록 전에 세 가지를 챙기세요

| 준비할 것 | 확인 방법 |
|---|---|
| 실제로 쓰는 홈페이지 주소 | https인지, 앞에 www가 붙는지까지 주소창에 보이는 그대로 적어 둡니다 |
| 사이트 관리 권한 | 파일을 올리거나 head에 코드를 넣을 수 있어야 합니다. 제작사가 관리한다면 미리 요청합니다 |
| 사이트맵 주소 | 보통 「홈페이지 주소/sitemap.xml」입니다. 브라우저에 직접 입력해 열리는지 봅니다 |

처음 막히는 곳은 대개 두 번째 줄입니다. 제작사와 연락이 끊겨 관리자 계정을 모르는 경우가 꽤 있습니다. 그렇다면 서치어드바이저보다 계정 찾기가 먼저입니다.

아래에 적은 메뉴 이름은 서치어드바이저 개편에 따라 조금씩 바뀔 수 있습니다. 이름이 다르더라도 등록, 소유 확인, 제출, 요청이라는 흐름은 같습니다.

## 1단계: 사이트 등록과 소유 확인

1. 서치어드바이저에 네이버 아이디로 로그인한 뒤 웹마스터 도구로 들어갑니다.
2. 사이트 등록 칸에 준비한 주소를 입력합니다.
3. 소유 확인 방법을 고릅니다. 안내된 HTML 파일을 내려받아 사이트 최상위 폴더에 올리는 방식과, 안내된 메타 태그를 메인 페이지 head에 넣는 방식이 있습니다.
4. 파일이나 태그를 넣은 뒤 소유확인 버튼을 누릅니다.

제작 도구로 만든 홈페이지라면 관리자 화면의 SEO 설정이나 코드 삽입 메뉴에 메타 태그를 붙여 넣는 칸이 있는 경우가 많습니다.

한 가지는 꼭 기억해 두세요. **소유 확인용 파일이나 태그는 등록이 끝난 뒤에도 지우지 않는 편이 안전합니다.** 확인 수단이 사라지면 소유 확인이 풀릴 수 있습니다. 홈페이지를 리뉴얼하면서 이 태그가 빠지는 일이 종종 생기는데, 리뉴얼 때 함께 챙길 항목은 [홈페이지 리뉴얼 전에 먼저 점검할 일곱 가지](/insights/website-renewal-checklist/)에 정리해 두었습니다.

## 2단계: 사이트맵과 RSS 제출

사이트맵은 우리 사이트에 어떤 페이지가 있는지 적은 주소 목록입니다. 웹마스터 도구에서 사이트를 고른 뒤 요청 메뉴의 사이트맵 제출에 사이트맵 주소를 넣으면 됩니다.

RSS는 새 글이 올라올 때마다 갱신되는 목록입니다. 공지, 칼럼, 시공 사례처럼 글이 꾸준히 올라오는 게시판이 있다면 같은 요청 메뉴의 RSS 제출에도 주소를 넣어 두세요. 새 글을 검색로봇이 더 빨리 발견하는 데 도움이 됩니다. 게시판 없이 회사 소개만 있는 사이트라면 사이트맵만으로 충분합니다.

제출 직후 상태가 바로 바뀌지 않아도 당황할 필요는 없습니다. 처리에는 시간이 걸립니다. 다만 오류가 표시된다면 사이트맵 주소를 브라우저에서 다시 열어 보세요. 열리지 않거나 내용이 비어 있다면 제작 도구 설정에서 사이트맵 생성이 꺼져 있을 가능성이 큽니다.

## 3단계: robots.txt 확인과 수집 요청

사이트맵을 냈는데도 페이지가 수집되지 않는다면 robots.txt가 검색로봇을 막고 있는지 봐야 합니다. 웹마스터 도구의 검증 메뉴에서 robots.txt 내용을 확인할 수 있습니다. 개발 중에 모든 로봇을 막아 둔 설정이 오픈 뒤에도 남아 있는 경우가 있습니다.

그다음 요청 메뉴의 웹 페이지 수집에서 중요한 페이지를 하나씩 요청합니다.

- 메인 페이지
- 서비스별 설명 페이지
- 가격·비용 안내 페이지
- 회사 소개와 오시는 길

하루에 요청할 수 있는 개수에는 한도가 있으니, 새로 만들었거나 내용을 크게 고친 페이지 위주로 고릅니다. 수집 요청은 빨리 읽어 달라는 신호일 뿐입니다. 노출 여부나 순위가 이 버튼으로 정해지지는 않습니다.

## 등록한 뒤 첫 한 달 동안 볼 것

등록 직후에는 리포트에 보이는 숫자가 거의 없습니다. 이후 한 주에 한 번 정도 들어가 아래 네 가지만 보시면 됩니다.

1. 수집 현황: 네이버가 우리 페이지를 실제로 가져가고 있는지
2. 수집 오류: 접근이 막히거나 없는 주소로 나오는 페이지가 있는지
3. 검색 노출과 클릭: 어떤 검색어로 우리 사이트가 보였고 눌렸는지
4. 사이트맵 처리 상태: 제출한 사이트맵에 오류가 남아 있지 않은지

Google도 방식은 같습니다. Search Console에 사이트를 등록하고 사이트맵을 제출하면 됩니다. 두 곳을 같은 날 해 두면 관리가 편합니다. 네이버 공식 도움말은 [네이버 서치어드바이저](https://searchadvisor.naver.com/)에서 볼 수 있습니다.

직접 하기 번거롭다면 제작 단계에서 맡기는 방법도 있습니다. 미래애드원의 [홈페이지 제작·운영](/services/website/)에는 제목 구조·메타·사이트맵·색인 같은 기초 테크니컬 SEO가 들어가고, [SEO·AEO·GEO 통합 최적화](/services/seo-aeo-geo/)에서는 색인·크롤링 점검을 월간 관리로 이어 갑니다.

## 자주 묻는 질문

### Q. 네이버 블로그도 서치어드바이저에 등록해야 하나요?
아닙니다. 네이버 블로그는 네이버가 운영하는 서비스라 따로 등록하지 않아도 됩니다. 서치어드바이저 등록은 직접 도메인을 가진 홈페이지가 대상입니다.

### Q. 등록하면 바로 검색에 나오나요?
바로 나오지는 않습니다. 수집과 반영에는 며칠에서 몇 주가 걸릴 수 있고, 등록했다고 노출이 보장되지도 않습니다. 등록은 네이버가 우리 사이트를 찾아 읽을 수 있도록 길을 열어 두는 단계입니다.

### Q. www가 붙은 주소와 안 붙은 주소를 둘 다 등록해야 하나요?
실제로 쓰는 대표 주소 하나만 등록하면 됩니다. 다른 주소로 들어와도 대표 주소로 자동 이동되게 설정해 두면, 검색로봇이 같은 페이지를 두 번 읽는 일도 막을 수 있습니다.
